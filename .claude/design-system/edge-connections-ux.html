Edge & Connection UX Design

Architecture workspace upgrade — fixing node connections, adding discoverable edge type selection, and creating a professional inline edge toolbar. Replaces hidden right-click context menu with always-visible interaction patterns.

BUG FIX 1. Node Handle Fix — Bidirectional Connections

The current implementation sets all 4 handles to type="source", meaning there are no target handles for connections to land on. Nodes can initiate connections but cannot receive them.

Before — Broken

API Gateway
SRC SRC SRC SRC

All 4 handles are type="source"
No target → Can't drop connections onto node

After — Fixed

API Gateway
SRC+TGT SRC+TGT SRC+TGT SRC+TGT

Paired handles at each position: source + target
Overlapping visually — one dot, two connections

Implementation

Each position renders TWO overlapping <Handle> elements:

Position Source Handle ID Target Handle ID Visual
Top top-src top-tgt Single 8px dot, glow on hover
Bottom bottom-src bottom-tgt Single 8px dot, glow on hover
Left left-src left-tgt Single 8px dot, glow on hover
Right right-src right-tgt Single 8px dot, glow on hover

The target handle sits directly behind the source handle (same position, same size). Target handles get z-index: 0, source handles get z-index: 1. React Flow's hit testing detects both.

UX UPGRADE 2. Edge Type Selection — Three-Tier Approach

The current edge style selection relies entirely on a right-click context menu, which is undiscoverable. The new design provides three complementary ways to set edge types, following progressive disclosure principles.

Tier 1 — Canvas Toolbar with Edge Type Selector

The existing canvas toolbar gets a new "Connection Type" section. Users pick the style before drawing connections. The selected type persists until changed.

Tier 2 — Inline Edge Toolbar (on select)

When a user clicks/selects an edge, a compact floating toolbar appears at the edge midpoint. This replaces the need for right-click entirely. The toolbar provides all edge actions in one visible, intuitive interface.

Appears on edge click. Positioned at edge midpoint using EdgeLabelRenderer.

Toolbar Anatomy

ElementActionBehavior
Style buttons (3) Change edge style Active button highlighted with cyan background. Click to switch.
Label input Add/edit edge label Always visible. Type to set label, shows as pill on edge when not selected.
Delete button Remove edge Red hover state. Removes edge with undo snapshot.
This toolbar lives INSIDE the LabeledEdge component, rendered via EdgeLabelRenderer. Only visible when the edge's selected prop is true.

Tier 3 — Keyboard Shortcuts

Power users can change edge styles without clicking, using number keys when an edge is selected.

1 Set selected edge(s) to Solid
2 Set selected edge(s) to Dashed
3 Set selected edge(s) to Dotted
L Focus label input on selected edge
Delete / Backspace Delete selected edge(s) — already works
